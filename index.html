1 Şəbəkə Konfiqurasiyası
x.x.x = Sizin NAT şəbəkəniz

Aşağıdakı parametrlərlə host konfiqurasiyası aparın:

  • Hostname: server1.corp.example.com
  • IP Address: x.x.x.77
  • Netmask: 255.255.255.0
  • Gateway: x.x.x.2
  • Nameserver: x.x.x.2
2 Local Repository Yaradılması

Aşağıdakı lokal repository-ləri konfiqurasiya edin (daimi olaraq mount olunmalıdır):

  • file:///MyRepo/BaseOS
  • file:///MyRepo/AppStream
Repository faylları /MyRepo direktoriyasında yerləşir və sistem yenidən başladıqdan sonra da əlçatan olmalıdır.
3 SELinux və Firewall Konfiqurasiyası

HTTP servisi yükləyin, 8989 portunu təyin edin. Bu məzmunu SELinux və Firewall konfiq edərək əlçatanlaşdırın.
